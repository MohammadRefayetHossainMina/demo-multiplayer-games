Open a file. This world is night ops, tight corridors, and one life that matters.

FILE 01 — The rule

You drop into the sector alone. Kill the boss. Grunts and tacticals guard the lane and come back. There is no extraction until the boss is down or you are. Ammo is counted. Corners are fatal. Hesitation is a death sentence.

FILE 02 — City after dark

Streetlights fail in strips. Industrial halls echo. Demo maps use the same default facilities you will see at launch — no hidden vendor rooms, no elite spawns.

FILE 03 — Why the demo is limited

Command wants every operator on equal footing. Default guns only. The tournament stays inactive until Dual Fire is ready for commercial release. We will inform everyone then.
